# Manual de usuario de StockFlow

## Entrar y salir

1. Abra el navegador de Internet y escriba la dirección de StockFlow que le dio el administrador.
2. Escriba su **Email** y **Contraseña**, y presione **Ingresar**.
3. Para salir, presione **Cerrar sesión** en el menú de la izquierda.

Cada persona debe usar su propia cuenta. Las opciones que aparecen dependen de su rol:

- Administrador: puede usar todas las secciones.
- Vendedor: puede consultar el resumen, registrar ventas y ver reportes.
- Repositor: puede consultar el resumen, revisar inventario, registrar reposiciones y ver reportes.

## Conocer la pantalla principal

Después de entrar, verá el Dashboard (resumen). Allí aparecen indicadores del negocio, ventas recientes y avisos de productos con stock bajo. Para abrir otra sección, presione su nombre en el menú de la izquierda.

Los formularios tienen campos para completar y botones para guardar. Los campos marcados como obligatorios no se pueden dejar vacíos. Si aparece un mensaje de error, lea la indicación, corrija el dato y vuelva a intentarlo.

## Registrar una venta

Disponible para administradores y vendedores.

1. Abra **Ventas**.
2. En **Producto**, seleccione el producto. El sistema muestra su precio y las unidades disponibles.
3. Escriba la **Cantidad** y presione **Agregar a la venta**. Repita para agregar otros productos.
4. Revise los productos y el **Total de la venta**.
5. Seleccione el canal de venta: **Presencial**, **Delivery** u **Online**.
6. Presione **Confirmar venta** una sola vez y espere el mensaje de confirmación. La venta queda registrada y el stock se actualiza.

Si un producto no aparece o no hay suficiente stock, pida al administrador o al repositor que revise el inventario. No confirme la venta nuevamente si ya apareció como registrada.

## Consultar o actualizar el inventario

Disponible para administradores y repositores.

- Para buscar un producto, escriba su nombre en **Buscar producto**.
- La tabla muestra el precio, las existencias, el mínimo y el estado. **Stock bajo** significa que las existencias llegaron al mínimo o están por debajo.
- Para agregar un producto, presione **Nuevo producto**, complete sus datos y presione **Guardar producto**. El precio de venta debe ser mayor que el precio de costo.
- Para cambiar los datos de un producto, presione **Editar**, actualice los campos y guarde.
- Para dejar de ofrecer un producto, presione **Retirar** y confirme si aparece la pregunta. El producto se retira de la lista activa, pero su historial se conserva.

## Registrar una reposición

Disponible para administradores y repositores.

1. Abra **Reposición**.
2. Seleccione el producto que llegó.
3. Escriba la cantidad recibida y, si lo desea, agregue una nota, como el proveedor.
4. Presione **Actualizar existencias** y espere la confirmación.

Registre solo productos que realmente recibió. La entrada quedará en el historial y aumentará el stock.

## Registrar y revisar gastos

Disponible para administradores.

1. Abra **Gastos** y complete la categoría, descripción, monto y fecha.
2. Presione **Guardar gasto**. Compruebe que el gasto aparezca en la tabla.
3. Para corregir un registro, presione **Editar** en su fila y guarde los cambios.
4. Para quitar un gasto, presione **Eliminar** y confirme. Revise bien antes de hacerlo.

## Ver reportes

1. Abra **Reportes**.
2. Elija las fechas de inicio y fin.
3. Seleccione el tipo: **Ventas**, **Stock** o **Gastos**.
4. Presione **Generar**. Los resultados aparecerán debajo.

El reporte de stock muestra las existencias actuales; los reportes de ventas y gastos muestran registros del período elegido.

## Administrar usuarios

Disponible para administradores.

1. Abra **Usuarios** y complete nombre, email, contraseña y rol.
2. Presione **Crear usuario** y comunique los datos de acceso directamente a esa persona, no en un lugar público.
3. Para impedir que una persona vuelva a entrar, presione **Desactivar** junto a su nombre. Para permitirle entrar de nuevo, presione **Activar**.

## Si necesita ayuda

Si no puede entrar, ve información que no esperaba o una operación no se confirma, anote el mensaje que aparece y avise al administrador. No intente repetir una venta o reposición si no sabe si se guardó; primero pida que revisen el historial.
